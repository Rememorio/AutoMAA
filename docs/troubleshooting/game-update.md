# 游戏更新与人工处理

游戏包体、游戏内数据和 MAA 识别数据是不同内容。AutoMAA 可以更新 MAA 引擎与识别数据；游戏的下载、登录和确认需要手动完成。MAA 的维护方式见[更新应用与 MAA](../guide/updates)。

## 游戏大版本更新后

1. 暂停相关方案的定时运行。
2. 在 PlayCover 中手动更新对应游戏 App，按连接环境要求重新确认 MaaTools 已启用。
3. 启动每个服务器客户端，等待游戏内数据下载和解压完成。
4. 处理协议、公告或重新登录，确认可以进入登录页或主界面。
5. 在 AutoMAA 检测 MAA 环境，按需更新 MAA 或识别数据。
6. 有人值守地运行一次方案，确认稳定后恢复定时。

初次下载或解压可能持续较长时间，超过自动启动的等待时间；这时不要反复运行方案等待它自行完成。

## 运行中提示“需要手动处理”

这通常表示游戏仍在更新、维护、要求登录或停留在 MAA 无法处理的界面。先查看活动记录中的具体原因，再手动打开相应客户端处理。

AutoMAA 会关闭并跳过受影响的客户端，其他能够安全启动的客户端仍可继续；连接归属无法确认时会停止整个流程。它不会代替用户接受协议、填写验证码或反复点击未知弹窗。

如果记录的是账号匹配或 MaaTools 连接错误，转到[常见问题](./common)排查配置。

## 游戏界面已经变化，MAA 尚未适配

关注 [MAA Releases](https://github.com/MaaAssistantArknights/MaaAssistantArknights/releases)与上游已知问题。暂时关闭受影响的任务，保留已经确认可用的任务；不要通过增加重试次数来强行操作新界面。

AutoMAA 负责调度 MAA 已支持的能力，不能自行修复上游识别规则。若提示的是“引擎与识别数据不兼容”，则应按[MAA 更新失败](../guide/updates#更新失败时)处理，而不是反复启动游戏。
