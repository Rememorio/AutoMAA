# 每日自动运行

AutoMAA 使用 macOS LaunchAgent 在指定时间启动无界面 Runner。只有在手动完整跑通一次后，才建议启用。

## 启用条件

- 用户保持登录状态；LaunchAgent 限制在 Aqua 图形会话中运行。
- Mac 没有关机；睡眠期间错过的时间不保证补跑。
- 游戏无需更新、重新登录、验证码或协议确认。
- `maa-cli`、游戏 App、Bundle Identifier 和连接地址保持有效。
- 多账号匹配片段已经过人工验证。

## 设置时间

1. 打开“全局设置”。
2. 设置小时和分钟。
3. 开启“每日自动运行”。
4. 修改时间后点击“应用时间”。

界面显示“系统定时任务已安装”后，配置才真正生效。关闭开关会卸载对应 LaunchAgent。

## 运行期间

Runner 会：

- 使用进程锁阻止两个 AutoMAA 流程同时执行；
- 使用 `caffeinate` 避免工作流中途休眠；
- 继续使用当天断点；
- 将输出写入 AutoMAA 的日志目录。

如果你同时打开图形界面并再次启动任务，第二个流程会因为进程锁而拒绝运行。

## 游戏更新后的建议

大版本更新后先关闭定时运行，手动启动每个服务器一次：

1. 完成游戏包体更新；
2. 等待数据下载和解压；
3. 处理公告、协议或重新登录；
4. 确认能进入登录页或主界面；
5. 手动跑一次 AutoMAA，再恢复定时。

详见[游戏更新与人工处理](../troubleshooting/game-update)。
