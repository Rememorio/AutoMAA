# 每日自动运行

每个自动化方案都可以拥有自己的 macOS LaunchAgent。你可以让轻量日常在早上运行、完整日常在晚上运行，同时保留两个方案的手动运行入口。

只有在对应方案已经有人值守地完整跑通后，才建议启用定时。

## 启用条件

- 用户保持登录状态；LaunchAgent 限制在 Aqua 图形会话中运行。
- Mac 没有关机；睡眠期间错过的时间不保证补跑。
- 游戏无需更新、重新登录、验证码或协议确认。
- `maa-cli`、游戏 App、Bundle Identifier 和连接地址保持有效。
- 官服、Bilibili 与繁中服的多账号匹配片段已经过人工验证；YoStar 英/日/韩服只启用一个账号且游戏保持该账号已登录。

## 为方案设置时间

1. 在侧边栏打开要定时的自动化方案。
2. 在“定时运行”卡片中设置每天的时间。
3. 开启开关。
4. 修改已启用方案的时间后，点击“应用时间”。

界面显示“系统定时任务已安装”后，这个方案的配置才真正生效。关闭开关只卸载当前方案的 LaunchAgent，不影响其他方案。

## 多方案调度

每个 LaunchAgent 都用方案 UUID 启动无界面 Runner。Runner 只执行指定方案，不会根据当前界面选择或名称猜测。

如果两个方案设在同一时刻，进程锁只允许一个工作流运行；另一个会拒绝重复启动。因此建议给方案留出足够间隔，使前一个方案能够完成客户端关闭和端口释放。

运行期间 Runner 会：

- 使用进程锁阻止两个 AutoMAA 流程同时执行；
- 使用 `caffeinate` 避免工作流中途休眠；
- 继续使用当前方案当天的断点；
- 将输出写入 AutoMAA 的日志目录。

## 游戏更新后的建议

大版本更新后先关闭相关方案的定时运行，手动启动每个服务器一次：

1. 完成游戏包体更新；
2. 等待数据下载和解压；
3. 处理公告、协议或重新登录；
4. 确认能进入登录页或主界面；
5. 手动跑一次对应方案，再恢复定时。

详见[游戏更新与人工处理](../troubleshooting/game-update)。
