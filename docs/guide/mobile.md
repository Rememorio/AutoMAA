# 手机查看与控制

AutoMAA 手机端提供 iOS 和 Android 工程，查看 Mac 上的已有方案、执行状态和脱敏记录，并支持运行、继续未完成任务及安全停止。手机端不会修改账号、关卡、资源消耗或定时设置，也不提供游戏画面和远程桌面。

## 连接条件

- Mac 已安装并配置 AutoMAA，使用期间保持联网、唤醒且 AutoMAA 正在运行。
- 手机和 Mac 均安装 Tailscale，登录同一私人网络，访问规则允许手机连接 Mac 的 TCP 43827 端口。
- 在 Tailscale 管理页启用 MagicDNS 和 HTTPS 证书。首次启用可按 [Serve 官方说明](https://tailscale.com/docs/features/tailscale-serve) 完成授权。
- 手机端目前从 `Mobile/` 构建安装，没有 App Store、TestFlight 或应用市场下载入口。构建方式见[移动端开发](../development/mobile.md)。

不需要购买域名、申请公网 IP 或部署自己的云服务器。连接仍依赖 Tailscale 的协调服务，必要时经其加密中继；不是完全脱离第三方服务的离线方案。AutoMAA 仅使用私人网络的 Serve，不启用面向公网的 Funnel。

## 首次配对

1. 在 Mac 打开 **全局设置 → 手机连接**，开启 **允许手机连接**。该功能默认关闭。
2. 等待“手机连接已就绪”，点击 **配对手机**。
3. 手机打开 AutoMAA，点击 **添加 Mac**，输入这台手机的名称，扫描二维码；也可以在 Mac 复制配对信息后粘贴到手机。
4. 手机点击 **连接并请求授权**，随后在 Mac 核对设备名称并选择 **允许连接**。

配对信息五分钟后失效，只能使用一次。关闭配对窗口或重新生成会取消旧配对。不要把二维码或配对信息发给不信任的人。日后打开手机 App 会尝试连接上次使用的 Mac，不需要重复扫码。

## 日常操作

### 总览与方案

总览显示连接状态、当前阶段和进度，以及已有方案。点击方案查看执行账号、任务顺序、关键参数、待办和定时状态，再确认运行。手机与 Mac 使用同一套校验、串行调度和断点规则；已处理任务不会因为手机启动而强制重跑。结果未确认的作战必须在 Mac 检查处理。

定时显示使用 Mac 的时区，活动时间转换为手机当地时间。参数和执行记录在确认过程中发生变化时，旧运行请求会被拒绝，需刷新后重新确认。

**安全停止**针对当前这一轮运行：先终止 MAA 命令，再关闭当前客户端并清理连接。“已请求停止”不等于清理完成，请以随后同步的实际状态为准。

### 活动记录

活动每次加载 20 条运行记录，筛选和搜索作用于已经加载的记录；底部可加载更多。详情每次加载 30 条日志，最近在前，可展开诊断信息。历史记录只读，敏感账号片段、手机号和邮箱经统一脱敏。

手机最多展示前 100 个方案；账号、待办或整体内容过多时显示摘要及省略提示，完整配置在 Mac 查看。单条日志正文和详情分别最多显示 2048、4096 字符。

### 断线与操作结果

手机断网或切到后台不会停止 Mac 的任务。界面保留最近获取的信息并标注更新时间；连接恢复并获取新状态前不能发送控制操作。

操作发出后如果连接中断，App 显示“结果待确认”，不会自动重发启动命令。重新连接后先查询操作回执；Mac 重启或无法取得回执时，请核对活动记录，再选择 **已核对结果**。清除此提示不会停止或重新执行任务。

### 移除设备

在 Mac 的 **手机连接** 中撤销手机授权，会立即断开该手机，后续访问需重新配对。在手机的 **设备** 页面移除 Mac 只清除本机凭据，不撤销 Mac 上的授权。关闭手机连接不会中断正在运行的工作流。

## 排查连接

| 现象 | 检查方式 |
| --- | --- |
| 找不到 Tailscale | 安装 Mac 客户端并登录，然后重试 |
| 无法读取 Tailscale 状态 | 确认客户端已启动、已登录且连接正常；检查失效的命令行快捷方式 |
| HTTPS 设置未完成 | 在 Tailscale 管理页开启 HTTPS 证书及 MagicDNS，完成 Serve 的首次授权 |
| 43827 端口被占用 | 检查既有 Serve 配置；AutoMAA 不会覆盖其他服务或重置 Tailscale |
| Mac 显示就绪但手机连不上 | 检查两端 Tailscale、访问规则和 Mac 是否睡眠；先尝试同网，再用蜂窝网络验证 |
| 相机不可用 | 在系统设置允许相机，或使用粘贴配对信息 |
| 授权失效 | 在 Mac 撤销旧授权并重新配对 |

不支持远程唤醒、登录/验证码处理、后台推送、资源更新或配置修改。iOS 与 Android 的真实扫码、VPN、后台恢复及蜂窝网络仍应在各自真机验收。
