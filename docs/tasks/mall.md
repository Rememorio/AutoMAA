# 信用与购物

“信用与购物”调用 MAA 的 `Mall` 任务，可以组合以下行为：

- 访问好友基建领取信用；
- 领取信用并在信用商店购物；
- 按顺序优先购买指定商品；
- 避开购物黑名单；
- 信用溢出时无视黑名单；
- 只购买折扣物品，或保留 300 信用；
- 可选借助战打一局 OF-1，为次日获得更多信用。

## 购买顺序

MAA 会先按“优先购买”列表依次购买，再从左到右避开黑名单购买。如果开启“信用溢出时无视黑名单”，信用即将溢出时会继续购买以减少浪费。

商品名应使用当前游戏语言中 MAA 可以识别的名称，例如“招聘许可”“龙门币”或“家具零件”。不同服务器语言不同，请按对应 MAA 资源和游戏界面填写。

## 助战信用关

开启后，MAA 会使用指定编队借助战打一局 OF-1。这会额外进入作战并占用时间；第一次启用时请有人值守确认编队和关卡行为。
