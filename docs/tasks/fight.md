# 理智作战

理智作战调用 MAA 的 `Fight` 任务。初次使用建议保持不使用理智药和源石，并先在有人值守时验证一次。

## 关卡

| 选项 | 行为 |
| --- | --- |
| 当前/上次 | 不指定关卡，由 MAA 使用游戏当前或上次作战 |
| 1-7 | 固定执行 `1-7` |
| 龙门币 / 作战记录 | 使用 `CE-6` / `LS-6`，无法代理第六关时由 MAA 回落到第五关 |
| 采购凭证 / 技巧概要 / 碳素 | 使用 `AP-5` / `CA-5` / `SK-5` |
| 当期或固定剿灭 | 当期剿灭、切尔诺伯格、龙门外环或龙门市区 |
| OF-1 / OF-F3 | 别传中的固定关卡 |
| 自定义 | 直接填写 MAA 支持的关卡名 |

“当前/上次”最适合活动期间手动准备好关卡后继续刷取；固定关卡更适合长期日常。

## 消耗与次数

- **理智药**：允许使用普通理智药的数量。
- **临期理智药天数**：使用指定天数内到期的理智药，例如 `2` 表示两天内。AutoMAA 使用当前 MAA 参数 `medicine_expire_days`，不是已弃用的“药品数量”参数。
- **源石**：允许使用源石恢复理智。除非完全理解后果，建议保持关闭。
- **次数**：限制执行次数；留空时由理智和 MAA 行为决定。
- **连战**：“保持当前”不写入参数，`-1` 关闭切换，`AUTO` 自动选择当前可用最大次数，也可指定 1–10。可用上限仍以当前游戏和 MAA 适配为准。
- **博朗台模式**：使用 MAA 对应的节约理智策略。

::: danger 源石消耗不可恢复
自动使用源石会产生真实账号资源消耗。首次配置、游戏大版本更新或 MAA 尚未适配新作战界面时，请保持关闭。
:::

## 上游适配期间

如果游戏刚修改作战、连战或结算界面，应以 MAA 的当前适配状态为准。AutoMAA 只负责传递参数，不会绕过 MaaCore 的兼容性限制。必要时暂时关闭理智作战，先运行公招和基建等已确认任务。
