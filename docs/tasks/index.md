# 配置模式

每个账号的四类日常任务都可以单独启用、关闭和排序。任务卡中的“自定义参数”开关决定参数来源。

## MAA 默认参数

关闭“自定义参数”时，AutoMAA 会生成与 MAA 出厂行为一致的明确参数。适合希望跟随 MAA 常规默认逻辑的用户。

关闭开关不会删除 AutoMAA 中已经填写的自定义值；再次开启时会恢复它们。

## AutoMAA 自定义参数

开启后，只把界面上启用或填写的选项写入任务文件，便于不同账号使用不同策略。

::: warning 基建是一个重要例外
MAA 的默认基建参数会进行常规换班。若只想收菜而不换班，必须开启基建的“自定义参数”，AutoMAA 才会使用 `Infrast mode = 20000`。
:::

## 任务顺序

任务按照账号编辑页中的顺序逐一执行。常见顺序是：

```text
理智作战 → 公开招募 → 基建收菜 → 领取奖励
```

也可以根据活动或账号情况调整。排序只影响当前账号，不会改变其他账号。
