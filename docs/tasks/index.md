# 任务与方案

任务属于自动化方案，而不是账号。一个方案统一定义任务顺序和参数，再作用于所有已启用账号或指定账号。

这让同一批账号可以同时拥有不同策略，例如：

```text
轻量日常：理智作战 → 公开招募 → 基建仅收菜 → 领取奖励
完整日常：理智作战 → 公开招募 → 基建完整换班 → 信用与购物 → 领取奖励
```

## MAA 推荐参数

关闭任务卡中的“自定义参数”时，AutoMAA 会生成与当前 MAA 日常行为对齐的推荐参数，并尽量省略拥有稳定 Core 默认值的可选字段。关闭开关不会删除已经填写的自定义值；再次开启时会恢复它们。

## AutoMAA 自定义参数

开启后，AutoMAA 使用界面中明确显示的参数。需要不同策略时可以复制方案，再修改副本，而无需复制客户端或账号。

::: warning 基建模式需要明确选择
MAA 的推荐基建参数会进行常规换班。若只想收菜，请开启“自定义参数”并选择 `Infrast mode = 20000` 的“仅收菜”。完整换班使用 `mode = 0`，自定义排班使用 `mode = 10000`。
:::

## 任务顺序与断点

任务按照方案编辑页中的顺序逐一执行。排序会应用到该方案的所有目标账号，不影响其他方案。

成功断点按“方案 + 账号 + 任务”保存。因此早上轻量方案完成过理智作战，不会让晚上完整方案跳过同名任务。
