# 任务配置

一个方案统一定义任务顺序和参数，再作用于所有已启用账号或指定账号。不同账号需要不同参数时，可以复制方案并调整目标账号。

## 支持的任务

| 任务 | 常见用途 |
| --- | --- |
| [理智作战](./fight) | 跟随游戏关卡、固定刷取、剿灭与常规关卡恢复 |
| [公开招募](./recruit) | 刷新标签、设置招募、保留需要确认的槽位 |
| [基建](./infrast) | 仅收菜、完整换班或使用自定义排班 |
| [信用与购物](./mall) | 访问好友、收取信用、按优先级购物 |
| [领取奖励](./award) | 领取任务、邮件和活动奖励 |

例如，轻量方案可安排“理智作战 → 公开招募 → 基建仅收菜 → 领取奖励”；完整方案则加入常规换班和信用购物。

## 推荐参数还是自定义参数

选择任务后，在右侧“参数模式”选择“MAA 推荐参数”或“自定义参数”。推荐模式使用 AutoMAA 对齐 MAA 的设置；自定义模式使用保存的参数。反复切换不会丢失此前输入，任务停用后参数也会保留。

::: tip 只收基建产物
选择“自定义参数”，基建模式使用“仅收菜”。切换到“MAA 推荐参数”会使用常规换班设置。
:::

任务列表可直接拖动排序，右键菜单也提供上移、下移。每类任务在一个方案中保留一份配置，用行内开关启用或停用。选择任务后，常用参数在右侧直接展开，修改自动保存。执行账号、定时和重试策略在“执行安排…”中一起应用。

任务按方案中的顺序执行，排序对该方案所有目标账号生效。成功步骤按方案保存当日断点，多个方案不会互相跳过；详见[执行流程与续跑](../guide/workflow)。
