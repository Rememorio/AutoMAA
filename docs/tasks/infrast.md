# 基建收菜

AutoMAA 的自定义基建任务面向“只领取产物和使用无人机，不进行干员换班”的场景。

## 必须开启自定义参数

开启“自定义参数”后，AutoMAA 使用 MAA 的 `Infrast mode = 20000`。可以选择：

- 制造站；
- 贸易站；
- 会客室；
- 无人机用途。

::: warning 关闭自定义参数会换班
关闭开关后使用 MAA 的常规默认基建模式，可能进行完整换班。如果你的目标只是收菜，请始终保持自定义参数开启。
:::

## 无人机用途

| 选项 | 对应设施或产品 |
| --- | --- |
| 不使用 | 保留无人机 |
| 贸易站 · 龙门币 | 加速龙门币订单 |
| 制造站 · 作战记录 | 加速经验书生产 |
| 制造站 · 赤金 | 加速赤金生产 |
| 贸易站 · 合成玉 | 加速合成玉订单 |
| 制造站 · 源石碎片 | 加速源石碎片 |
| 制造站 · 芯片 | 加速芯片生产 |

无人机用途必须与账号当前基建设施和生产内容相符。没有匹配设施时，MAA 可能无法完成加速，但仍会继续处理可领取内容。

## 会客室

启用会客室会同时允许 MAA 处理会客室留言板、线索交流和线索赠送等相关行为。如果只需要制造站与贸易站产物，请保持关闭。
