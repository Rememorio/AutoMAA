# 基建

AutoMAA 在同一张任务卡中明确区分两种 MAA 基建模式。

## 仅收菜，不换班

使用 MAA `Infrast mode = 20000`。该模式不会进行完整干员换班，但保留收取产物、使用无人机、会客室信息板、线索交流和赠送等基础操作。

适合早间或高频轻量方案。

## 完整换班

使用 MAA `Infrast mode = 0` 的单设施最优解。可以配置：

- 需要处理的制造站、贸易站、发电站、控制中枢、会客室、办公室、宿舍、加工站和训练室；
- 换班心情阈值；
- 宿舍空位补信赖未满干员；
- 是否避免将已进驻干员放入宿舍；
- 源石碎片补货与训练完成后继续专精。

适合每天固定一次的完整基建维护方案。

## 无人机用途

| 选项 | 对应设施或产品 |
| --- | --- |
| 不使用 | 保留无人机 |
| 贸易站 · 龙门币 | 加速龙门币订单 |
| 制造站 · 作战记录 | 加速经验书生产 |
| 制造站 · 赤金 | 加速赤金生产 |
| 贸易站 · 合成玉 | 加速合成玉订单 |
| 制造站 · 源石碎片 | 加速源石碎片 |
| 制造站 · 芯片 | 加速芯片生产 |

无人机用途必须与账号当前基建设施和生产内容相符。没有匹配设施时，MAA 可能无法完成加速，但仍会继续处理可执行内容。

::: warning MAA 默认参数
关闭“自定义参数”会回到 MAA 的常规完整换班默认值。只收菜方案应保持自定义参数开启，并明确选择“仅收菜，不换班”。
:::
