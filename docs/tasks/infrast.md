# 基建

AutoMAA 在同一张任务卡中明确区分三种 MAA 基建模式。

## 仅收菜

使用 MAA `Infrast mode = 20000` 的一键轮换模式。它会跳过控制中枢、发电站、宿舍和办公室，其余设施不进行常规换班，但保留收取产物、使用无人机、会客室信息板、线索交流和赠送等基础操作。

适合早间或高频轻量方案。

## 完整换班

使用 MAA `Infrast mode = 0`，由所安装的 MaaCore 计算干员组合并安排常规换班。可以配置：

- 需要处理的制造站、贸易站、发电站、控制中枢、会客室、办公室、宿舍、加工站和训练室；
- 换班心情阈值；
- 宿舍空位补信赖未满干员；
- 是否避免将已进驻干员放入宿舍；
- 源石碎片补货与训练完成后继续专精。

适合每天固定一次的完整基建维护方案。

当前 MaaCore 的常规换班算法支持设施内及跨设施组合，所选设施作为启用集合，换班顺序由算法安排。AutoMAA 暂未提供跨设施组合和菲亚梅塔恢复的专用参数，未传入的选项遵循所安装 MaaCore 的默认值；上游 GUI 的相关开关不会自动应用到 AutoMAA。

“上岗最低心情”只在本次换班选择候选干员时生效：低于阈值的干员不会被选中，但 MAA 不会在干员工作到该阈值时自动再次换班。AutoMAA 的自定义参数默认使用 90%，为每天一次完整换班预留心情；降低阈值可以增加可选干员，但可能使其在下次换班前进入疲劳。若切换到“MAA 推荐参数”，则遵循 MAA 的通用默认值 30%。

## 自定义排班

使用 MAA `Infrast mode = 10000`。选择符合 [MAA 基建排班协议](https://docs.maa.plus/zh-cn/protocol/base-scheduling-schema.html)的 JSON 文件，并填写从 `0` 开始的方案序号。

自定义排班文件由 MAA 读取，AutoMAA 不修改内容。文件不存在时，图形界面和无界面 Runner 都会拒绝开始该方案；移动文件后需要重新选择路径。

## 无人机用途

| 选项 | 对应设施或产品 |
| --- | --- |
| 不使用 | 保留无人机 |
| 贸易站 · 龙门币 | 加速龙门币订单 |
| 制造站 · 作战记录 | 加速经验书生产 |
| 制造站 · 赤金 | 加速赤金生产 |
| 贸易站 · 合成玉 | 加速合成玉订单 |
| 制造站 · 源石碎片 | 加速源石碎片 |
| 制造站 · 芯片 | 加速芯片生产 |

无人机用途必须与账号当前基建设施和生产内容相符。没有匹配设施时，MAA 可能无法完成加速，但仍会继续处理可执行内容。

::: warning MAA 推荐参数
关闭“自定义参数”会回到 MAA 推荐的常规完整换班参数。只收菜方案应保持自定义参数开启，并明确选择“仅收菜”。
:::
