# 公开招募

公开招募调用 MAA 的 `Recruit` 任务。AutoMAA 可以为每个方案配置次数、刷新、加急和自动确认星级，并应用到该方案的目标账号。

## 常用设置

- **刷新**：在没有期望标签时使用刷新次数。
- **次数**：本次最多处理的招募槽位数量。
- **使用加急许可**：完成设置后使用加急许可。
- **自动确认 3/4/5/6 星**：允许 MAA 自动选择并确认对应星级组合。
- **三星首选标签**：三星组合出现时，优先选择这里列出的标签。
- **额外标签策略**：使用标准选择、总是选择三个标签，或尽量选择更多高星标签。
- **保留并跳过**：识别到列表中的任意标签时保留当前槽位，例如 `支援机械`。AutoMAA 使用当前 MAA 参数 `preserve_tags`，不会生成已弃用的 `skip_robot`。

推荐从“刷新开启、4 次、不使用加急、自动确认 3/4 星、保留支援机械”开始；需要不同资源策略时可复制方案并选择对应账号。

::: tip 高星标签
如果没有开启对应星级的自动确认，MAA 会保留需要人工判断的高价值组合。运行后请查看游戏和活动记录，避免长期占用招募槽位。
:::

公开招募页面或标签识别异常时，该任务会失败或要求人工处理，但不会把失败步骤写入当天完成记录。
