# 公开招募

为方案配置招募次数、刷新、加急和自动确认星级。参数应用于该方案的全部目标账号。

## 常用设置

| 设置 | 含义 |
| --- | --- |
| 刷新 | 没有期望标签时使用刷新次数 |
| 次数 | 本次最多处理的招募槽位数量 |
| 使用加急许可 | 完成设置后使用加急许可 |
| 自动确认星级 | 允许 MAA 自动选择并确认对应星级组合 |
| 三星首选标签 | 三星组合出现时优先选择的标签 |
| 额外标签策略 | 标准选择、总是三个标签或尽量选择更多高星标签 |
| 保留并跳过 | 识别到指定标签时保留槽位，例如 `支援机械` |

“MAA 推荐参数”使用 4 次、不刷新、不使用加急、自动确认 3/4/5 星，并保留支援机械。需要调整时开启自定义参数，先确认设置是否适合自己的招募资源。

## 高星与保留标签提醒

MAA 识别到 5★/6★、特殊标签或“保留并跳过”的标签，且没有明确处理记录时，AutoMAA 会在活动记录中突出显示并提示检查。这是需要留意的结果，不代表任务失败。

公招任务成功结束，且 MAA 明确报告该条结果已自动确认招募或已刷新时，只保留普通活动记录，不再计入“需要确认”或发送重要通知。同一轮中其他未处理的结果仍会提醒；只开启自动确认、只报告招募总次数或任务失败，不足以证明某个槽位已经处理。

启用[重要通知](../guide/scheduling#查看后台结果与通知)后，会在该次公招任务结束时提醒，不必等整套方案完成。查看实际识别标签；未开启自动确认或命中保留条件时，前往游戏处理相应槽位。

识别异常导致的失败不会写入当天成功记录，可从活动详情查看原因。

以上判断适用于新运行，已有活动记录保留当时的提示，不会自动改写历史。
