# 公开招募

为方案配置招募次数、刷新、加急和自动确认星级。参数应用于该方案的全部目标账号。

## 常用设置

| 设置 | 含义 |
| --- | --- |
| 刷新 | 没有期望标签时使用刷新次数 |
| 次数 | 本次最多处理的招募槽位数量 |
| 使用加急许可 | 完成设置后使用加急许可 |
| 自动确认星级 | 允许 MAA 自动选择并确认对应星级组合 |
| 三星首选标签 | 三星组合出现时优先选择的标签 |
| 额外标签策略 | 标准选择、总是三个标签或尽量选择更多高星标签 |
| 保留并跳过 | 识别到指定标签时保留槽位，例如 `支援机械` |

默认推荐设置为刷新开启、4 次、不使用加急、自动确认 3/4 星，并保留支援机械。先确认是否适合自己的招募资源。

## 高星与保留标签提醒

MAA 识别到 5★/6★、特殊标签或“保留并跳过”的标签时，AutoMAA 会在活动记录中突出显示。这是需要留意的结果，不代表任务失败。

启用[重要通知](../guide/scheduling#查看后台结果与通知)后，会在该次公招任务结束时提醒，不必等整套方案完成。查看实际识别标签；未开启自动确认或命中保留条件时，前往游戏处理相应槽位。

识别异常导致的失败不会写入当天成功记录，可从活动详情查看原因。
